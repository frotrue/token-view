# 구글 드라이브 동기화 설정

PC 앱이 사용 기록을 **각 사용자의 구글 드라이브**에 올리고, 휴대폰이 같은 구글 계정으로 그 기록을 읽어요. 별도 서버나 DB는 없어요.

- **저장 위치:** 드라이브의 숨겨진 앱 전용 공간(`appDataFolder`)이에요. 사용자의 일반 파일 목록에는 보이지 않아요. 이 앱은 사용자의 다른 파일을 볼 수 없어요.
- **권한(scope):** `drive.appdata`, 그리고 계정 표시용 `openid` / `email`만 요청해요.
- **용량:** 사용자 한 명당 수 MB예요. 업로드 1회는 gzip으로 압축해 약 100KB이고, 각자의 드라이브 용량에서 쓰여요. 개발자에게 비용이 들지 않아요.
- **삭제:** 사용자는 드라이브 웹의 **설정 → 앱 관리 → Token View → 숨겨진 앱 데이터 삭제**로 언제든 지울 수 있어요. 지워도 PC가 다음 동기화 때 다시 만들어요.

아래 1~5단계는 **개발자(배포하는 사람)가 한 번만** 하면 돼요. 사용자는 앱에서 "구글 계정으로 연결"만 누르면 돼요.

## 1. Google Cloud 프로젝트 만들기

1. <https://console.cloud.google.com>에서 새 프로젝트를 만들어요(예: `Token View`).
2. **API 및 서비스 → 라이브러리**에서 **Google Drive API**를 찾아 **사용**을 눌러요.

PC용과 휴대폰용 로그인 클라이언트는 **반드시 같은 프로젝트**에 만들어야 해요. 앱 전용 공간은 프로젝트 단위로 공유되기 때문이에요. 다른 프로젝트의 클라이언트로는 PC가 올린 기록을 볼 수 없어요.

## 2. OAuth 동의 화면 (Google Auth Platform)

1. **브랜딩:** 앱 이름(`Token View`)과 지원 이메일을 입력해요. 로고는 비워 두는 게 좋아요. 로고를 올리면 구글의 브랜드 검토가 필요할 수 있어요.
2. **대상:** **외부(External)**를 선택해요.
3. **데이터 액세스 → 범위 추가:** 다음 세 개를 추가해요.
   - `.../auth/drive.appdata`
   - `openid`
   - `.../auth/userinfo.email`
4. **게시 상태**
   - **테스트:** 테스트 사용자로 등록한 계정(최대 100개)만 로그인할 수 있어요. 또 PC 로그인이 **7일마다 만료**돼요. 처음 확인할 때는 본인 계정을 테스트 사용자로 추가하세요.
   - **프로덕션(앱 게시):** 누구나 로그인할 수 있고, 7일 만료도 없어져요. 위 세 범위는 민감·제한 범위가 아니라서 보통 구글 심사 없이 게시돼요. 콘솔이 범위 옆에 "민감" 또는 "제한"을 표시하면 심사가 필요하다는 뜻이니 그때 확인하세요.

## 3. OAuth 클라이언트 만들기 (두 개)

**API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**

| 용도 | 애플리케이션 유형 | 추가 설정 | 받는 값 |
|---|---|---|---|
| PC 앱 | **데스크톱 앱** | 없음 | 클라이언트 ID, 클라이언트 보안 비밀번호 |
| 휴대폰 웹앱 | **웹 애플리케이션** | 아래 참고 | 클라이언트 ID |

**웹 애플리케이션 클라이언트 설정**
- **승인된 자바스크립트 원본:** 모바일 웹앱 주소를 넣어요(예: `https://token-view.pages.dev`). 개발용으로 `http://localhost:1420`, `http://127.0.0.1:4173`을 추가해도 돼요.
- **승인된 리디렉션 URI:** 같은 주소 끝에 `/`를 붙여 넣어요(예: `https://token-view.pages.dev/`, `http://localhost:1420/`).

**데스크톱 앱의 보안 비밀번호**는 구글 문서상 설치형 앱에서는 비밀로 취급되지 않는 값이에요. PC 앱은 브라우저 로그인 후 `127.0.0.1` 임시 포트로 돌아오는 방식(PKCE)을 써요.

## 4. 빌드에 클라이언트 넣기

GitHub 저장소의 **Settings → Secrets and variables → Actions**에 등록해요.

| 이름 | 종류 | 값 |
|---|---|---|
| `TOKEN_VIEW_GOOGLE_CLIENT_ID` | Variable | 데스크톱 앱 클라이언트 ID |
| `TOKEN_VIEW_GOOGLE_CLIENT_SECRET` | Secret | 데스크톱 앱 보안 비밀번호 |
| `VITE_GOOGLE_CLIENT_ID` | Variable | 웹 애플리케이션 클라이언트 ID |

- 등록한 뒤 만든 릴리스와 베타 빌드부터 클라이언트가 포함돼요.
- 값이 없는 빌드에서도 PC 앱 **설정 → 휴대폰 연결 → 고급**과 웹앱의 **구글 클라이언트 ID** 칸에 직접 입력할 수 있어요.
- 로컬에서 웹앱을 빌드할 때는 `.env.local`에 `VITE_GOOGLE_CLIENT_ID=…`를 넣어요(`.env.example` 참고).

## 5. 모바일 웹앱 배포

`npm run build` 결과인 `dist/`를 HTTPS 정적 호스트의 **루트 경로**에 올려요. 기본 구성은 하위 경로 배포를 지원하지 않아요.

- **Cloudflare Pages(무료) 추천:** 저장소를 연결하고, 빌드 명령 `npm run build`, 출력 폴더 `dist`, 환경 변수 `VITE_GOOGLE_CLIENT_ID`를 설정해요. `_headers`(보안 헤더)와 `_redirects`가 그대로 적용돼요.
- **배포 주소:** 3단계의 자바스크립트 원본과 리디렉션 URI에 정확히 같은 주소가 등록돼 있어야 해요.

## 6. 동작 확인

1. PC 앱 **설정 → 휴대폰 연결 · 구글 드라이브 → 구글 계정으로 연결**을 눌러요. 브라우저에서 허용하면 앱에 계정이 표시되고, 잠시 후 "마지막 업로드"가 채워져요.
2. 휴대폰에서 웹앱을 열고 **구글 계정으로 연결**을 눌러 같은 계정을 선택해요. PC 이름과 비용이 PC 화면과 일치해야 해요.
3. 휴대폰에서 **PC에 최신 한도 요청**을 눌러요. PC가 켜져 있으면 1~2분 안에 요청 표시가 사라지고 캡처 시각이 갱신돼요.
4. 1시간 뒤 휴대폰을 다시 열면 **구글 다시 연결** 버튼이 나와요. 웹의 구글 토큰은 1시간짜리라 그래요. 누르면 바로 돌아오고, 그동안 저장된 기록은 계속 보여요.
5. PC 앱을 다시 시작해도 로그인이 유지돼야 해요. 로그인 정보는 Windows 자격 증명 관리자에 저장돼요. **연결 해제**를 누르면 토큰이 철회되고 삭제돼요.

## 드라이브 안의 파일 구조

모든 파일은 `appDataFolder` 안에 있어요. 휴대폰은 한 번의 목록 조회로 전부 읽어요.

| 파일 | 내용 | 쓰는 쪽 |
|---|---|---|
| `tv-snapshot-<PC ID>` | gzip으로 압축한 스냅샷 JSON(v1). 속성: PC 이름, `capturedAt`, `checkedAt`, `handled` | PC |
| `tv-request-<PC ID>` | 내용 없음. 속성: `nonce`, `at` | 휴대폰 |
| `tv-settings` | 내용 없음. 속성: 통화, 환율, 예산 3개, `rev` | 둘 다 (마지막에 쓴 쪽이 적용) |

**업로드 규칙 (PC)**
- 화면에 보일 내용이 바뀌었을 때만 올려요. 바뀌어도 최대 5분에 한 번이에요.
- 내용이 그대로면 5분마다 `checkedAt` 속성만 갱신해요(약 1KB). 휴대폰은 이 값으로 "몇 분 전 확인"을 표시해요.
- 휴대폰의 요청이나 **지금 동기화**는 5분 제한 없이 바로 올리고, 처리한 요청의 `nonce`를 `handled`에 남겨요.
- 요청 파일과 설정 파일은 1분마다 목록 조회 한 번으로 확인해요.

## 나중에 네이티브 모바일 앱으로 만들 때

- **같은 프로젝트에 클라이언트를 추가해요.** Android 또는 iOS 유형의 OAuth 클라이언트를 만들어요. 앱 전용 공간은 같은 프로젝트의 클라이언트끼리 공유되므로 같은 기록을 읽을 수 있어요.
- **로그인 방식만 바꾸면 돼요.** 네이티브 앱은 PKCE와 refresh token을 쓸 수 있어서 "1시간마다 다시 연결"이 없어져요. `src/cloud/google.ts`의 토큰 부분만 교체하면 되고, 파일 구조와 스냅샷 형식은 그대로 써요.
